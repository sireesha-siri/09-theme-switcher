### Completion Instructions

<details>
<summary>Functionality to be achieved</summary>
<br/>

- Initially, the application should be in **Light** theme mode
- The Light Mode button should have the **active** class initially
- When the **Dark Mode** button is clicked:
  - The theme should change to **Dark**
  - The text should display "Current theme: Dark"
  - The **Dark Mode** button should have the active class
  - The **Light Mode** button should no longer have the active class
- When the **Light Mode** button is clicked after selecting Dark theme:
  - The theme should change back to **Light**
  - The text should display **"Current theme: Light"**
  - The **Light Mode** button should have the active class
  - The **Dark Mode** button should no longer have the active class

</details>
